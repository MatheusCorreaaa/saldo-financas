# Saldo

Site de finanças pessoais em português. Inclui visão geral, extrato, orçamento e metas, recorrências e configurações.

## Rodar localmente

Na raiz do repositório, execute o comando abaixo com o Python 3.

```bash
python -m http.server 8000
```

Acesse [http://localhost:8000](http://localhost:8000). O site usa HTML, CSS e JavaScript e abre sem registros de exemplo.

Os lançamentos e as preferências ficam no armazenamento local do navegador. Use o mesmo navegador e endereço para acessar os dados salvos.
